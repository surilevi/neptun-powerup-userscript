# Support

Neptun PowerUp! is a small userscript project, not an official Neptun client.

For bugs, use the bug report template and include the userscript version, browser, userscript manager, and sanitized steps to reproduce.

For university-specific UI differences, use the compatibility report template. The most useful details are safe button labels, table column order, and sanitized DOM snippets.

For legal or acceptable-use questions, read `LEGAL_NOTICE.md` first. The project cannot decide whether your institution allows a specific workflow.
